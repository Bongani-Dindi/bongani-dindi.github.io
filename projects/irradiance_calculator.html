01

The project

This tool supports the UV chamber project by making lamp-array choices easier to investigate. It combines analytical screening with a finite-line-source calculation of irradiance across a rectangular specimen plane. The interface connects lamp spacing, height, emitting length, specimen dimensions and reflector assumptions to maps and performance measures.

The current source includes normalised, spectral and band-integrated modes, tabulated QUV spectral data, reflector sensitivity cases, a lamp-count search, an engineering dashboard and data exports. It is a preliminary design model. Comparing predictions with radiometer measurements remains a key step before using absolute estimates to qualify the chamber.

02

Project goals

  1. Compare realistic layouts. Evaluate lamp count, pitch, specimen distance and edge effects while keeping the mechanical arrangement visible.
  2. Use clear performance measures. Report minimum, maximum, centre and area-mean irradiance, alongside uniformity and the location of weak exposure.
  3. Keep optical quantities consistent. Distinguish relative distributions, spectral irradiance and band-integrated irradiance throughout the inputs, plots and exports.
  4. Make results reproducible and reviewable. Retain geometry and assumptions with exported results, and establish a route to checking the model against measured output.
03

Technical learning

Finite sources and numerical integration

The current model represents each lamp as a uniformly emitting finite isotropic line source and integrates contributions along its length using Gauss–Legendre quadrature. This has helped me connect source geometry, distance and incidence angle to the spatial distribution. It also shows why finite lamp ends and sample edges need attention when screening a layout.

Reflections and model boundaries

First-order specular image sources represent side and end reflectors, with reflected rays counted only when they intersect the finite reflector boundaries. Sensitivity cases make the reflectance assumption visible. I am learning to document the omitted effects—such as multiple reflections, diffuse reflection, shadowing and ageing—and use measurements to decide how much those simplifications matter.

Spectral data, radiant power and units

Working with the QUV spectral distribution has made the difference between source radiant output and specimen-plane irradiance much clearer. The spectral table describes irradiance at the test plane; it cannot be entered directly as one lamp’s emitted power. Spectral quantities use a per-wavelength basis, while band-integrated quantities cover a defined wavelength interval. Absolute spatial estimates require an appropriate lamp-output input.

Engineering software that supports comparison

The UI revisions focus on legible high-resolution figures, visible lamp positions, explicit plot bounds and clear input validation. The source keeps geometry and numerical controls in structured input records, and provides map and spectral CSV exports. I am learning that visual clarity, consistent units and traceable settings are part of model quality.

04

Soft skills & working habits

  • Iteration from a concrete problem. Reports of crowded figures, low resolution and confusing map zoom led to specific UI requirements. I am practising how to turn a visual complaint into changes that can be reviewed: layout, labels, source positions and stable comparison bounds.
  • Explaining uncertainty. The distinction between relative maps and absolute estimates has helped me communicate what a result supports. Making missing lamp-output information and modelling assumptions visible is an important part of presenting the tool responsibly.
  • Organising a technical handover. Separating inputs, calculations, plots and exports helps another reader follow the tool. The same structure helps me explain how a result was produced and what information is needed to reproduce it.
05

Detailed updates

A record of documented work and learning through September 2026. Future verification and delivery steps are listed separately.

29 September 2026

Spectral interpretation and export support

The current source contains the supplied UVA-340/UVA-340+ specimen-plane spectral table, interpolation at a reference wavelength and selected-band integration. Map and spectral CSV exports preserve labels and units. If lamp radiant output is absent, the spatial map remains relative while the separate spectral calculation can still be displayed.

Learning: a useful spectrum and an absolute lamp-output value answer different questions. Their input contracts must remain separate.

24 September 2026

A cleaner comparison interface

The interface work addressed figure resolution, overlapping plot elements, lamp-location overlays and the view used when parameters change. These changes make it easier to relate the mechanical arrangement to the specimen-plane distribution.

Learning: readable visual output reduces interpretation errors. A model comparison needs a clear frame of reference as well as a numerical answer.

September 2026

Geometry, uniformity and sensitivity

The calculator brings analytical screening together with numerical map evaluation and a search for a suitable lamp count. Reflector cases show how assumed surface behaviour changes the prediction, and the reported map identifies weak-exposure positions.

Next evidence: measured lamp output and an irradiance grid for comparison with the preliminary model.
